Types of graphs
Type A) **Directed**
- There are arrows pointing to nodes. "cause and effect"
	- rain --> bring an umbrella
	- A08 --> A48 (prerequisites)
	- BST search --> BST search (is recursive!)
	- Pacos Website --> Pacos website (home button) --> CMS page
Type B) **Undirected**
- There is no arrow; a "connection" is a bi-directional connection always.
	- Person1 -- Person2 (two people were in close proximity to each other)

Directed graphs are more generic / more information. Undirected graphs can be seen as a subset of directed graphs


Things related to graphs
a) The **Neighbourhood** of a node
- The nodes a node is connected to.
- Out-neighbourhood = links going out of a node. 
- In-neighbourhood = links going into a node
b) Degree: Size of a neighbourhood
- Useful for finding what has more connections (maybe whose more popular, or what works the best, etc.)
- The size of an out-neighbourhood would be the out-degree; same with in-degree
