$f(2x + 3) = \frac{3x}{x-1}$

### Solving for f(x) 
Solve for f(1)
- By logic, the argument for $f(2x+3)$ must equal 1. So, 2x + 3 = 1 . x is solved to be -1, so we pass *that* into $\frac{3x}{x-1}$ because when x is -1, 2x + 3 is the 1 we desire!
Solve for f(x)
- We do this by having a temporary variable "t" that is equal to the argument $2x + 3$. Then, we solve for x which gets us $x = \frac{t-3}{2}$, and replace that will every "x".
