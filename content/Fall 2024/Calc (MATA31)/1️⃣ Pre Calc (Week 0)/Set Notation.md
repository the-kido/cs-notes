Definition (not formal): A set is a collection of distinct elements

| Symbol            | Meaning                         | Example                       |
| ----------------- | ------------------------------- | ----------------------------- |
| $\in$             | is an element/member of         | $86\in\set{7, 86}$            |
| $\notin$          | is NOT an element/member of     | $86\notin\set{1,2,3}$         |
| $\subseteq$       | is a subset of                  | $\set{1}\subseteq\set{1,2,3}$ |
| $\cap$            | set union (merges sets)         |                               |
| $\cup$            | set intersect (common elements) |                               |
| $\emptyset$ or {} | empty set                       |                               |

"Name" = { "expression" : "restriction on variable in expression" }
- $S = \set{2n + 1 : n\in\mathbb{Z}\ and\ n > 0}$

How do you describe a union or intersection of A and B in set notation?
?
Union of A and B: $A \cup B = \{ x | x \in A \text{ or } x \in B\}$
Intersection of A and B: $A \cup B = \{ x | x \in A \text{ and } x \in B\}$

Is $(1, 4)$ a set, an interval, or both?
?
