#### f'(c)
if f'(c) = 0 and f''(c) > 0, then we have a local minimum
if f''(c) < 0 we have a local maximum.
f''(c) = 0 implies inflection 
- f''(c-h) > 0 and f''(c+h) < 0, we have CD
- f''(c-h) < 0 and f''(c+h) > 0, we have CU
- If no sign change, then it's constant.
