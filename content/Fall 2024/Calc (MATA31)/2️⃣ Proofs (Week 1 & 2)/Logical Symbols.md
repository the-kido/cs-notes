
| Symbol            | How to read it                                                                                                               | Usage          | Meaning                                                                 |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------- | -------------- | ----------------------------------------------------------------------- |
| $\implies$        | P "Implies" Q. <br>An <span class="definition">implication</span> or "if, then"                                              | $P \implies Q$ | If P is true, then Q is true<br>If P is false, then Q is true or false. |
| $\iff$ *or* $iff$ | P is "equivalent" to Q<br>P if and only if Q. <br><span class="definition">A two-way implication</span>, or "if and only if" | $P \iff Q$     | Both $P \implies Q$ and $Q \implies P$ must be true                     |
 For instance, if P and Q are [[Mathematical Statements]], $P \implies Q$ would read as "P implies Q" or [[Conditionals (or implications)#How to engrish|several other ways]]
- P is the hypothesis and Q is the conclusion
- It is **not necessary** that either A or B are actually *true*

Look at [[Conditionals (or implications in calc)]] for more details of the discrete version (which is pretty similar)

# Cards #calc-2 

What is an implication?
?
An if --> then statement. We assume the "Hypothesis" is true, and a correct implication will have the Conclusion true as well.
An implication with a false hypothesis is meaningless, but we can also say it's Vacuously True

Is the statement "If 37 < 0, then $\pi\in\mathbb{R}$" true or false?
?
