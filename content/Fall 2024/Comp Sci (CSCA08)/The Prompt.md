The `>>>` represents a  prompt for the [[Python Shell]]

If you have an unclosed parenthesis within the shell, python will assume you want to keep adding code within it, so it'll prompt you to another line. Look at the example below
```python
>>> print( 
... "hello world!"
... )

#Will output: hello world!
```


If you run a .py file, the prompt will remember that context and you can continue prompting as if the .py file was continuing to have lines added!
