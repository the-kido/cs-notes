We have Intersection $\cap$, Union $\cup$, and Difference \\

| Set Operation | What it looks like                                 |                                |
| ------------- | -------------------------------------------------- | ------------------------------ |
| Union         | $A \cup B = \{x \mid x \in A\ and\ x \in B\}$      | Gets only the parts in A and B |
| Intersection  | $A \cap B = \{x \mid x \in A\ or\ x \in B\}$       | Adds both A and B together     |
| Difference    | $A \backslash  B = \{x \mid x \in\ and\ x \in B\}$ | Rmoves everything in B from A  |

## Equivalences
$A \backslash (A \cap B)= A \backslash B$
$A \cup (B \cap C) = (A \cup B)  \cap (A \cup C)$
