
A <span class="definition">Truth Set</span> defines what sort of values are true or false for a statement.
- For instance, P(x) may stand for "x is prime" so P(x) = 23 is true whereas P(x) = 22 is false. To formally show what values are excepted, the set could look like $\{x | x \text{ is a prime number}\}$
If a statement is always false, its truth set is $\emptyset$, So $x \in \emptyset$ is always false. 

A general format would be: P(x) as $\{ x \in U | P(x) \}$ where U is the universe and P(x) is some statement. Sometimes you can neglect the $\in U$ part
