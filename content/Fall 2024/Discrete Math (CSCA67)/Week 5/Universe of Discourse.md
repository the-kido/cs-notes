 <span class="definition">Universe of discourse</span> All possible values for a variable.

 - $\forall x, P(x)$
	 - This is <span class="definition">Universally Quantified</span>
	 - true if P(x) is true for every element in the universe of discourse (false otherwise)
	 - P(x) is <span class="emphasis">universally true</span>
 - $\exists x, P(x)$
	 - This is <span class="definition">Existentially Quantified</span> 
	 - true if P(x) is true for some element in the universe of discourse (false otherwise)

#### When do you explicitly describe the universe of discourse?
The universe of discourse is implied so long as it's specified in words (Don't add $\in \mathbb{R}$ after N if the universe is specified to be "all real numbers")
