# SQL time

Projection is done with SELECT
You can do extended projection, you can rename attributes with `AS`
You can also do arithmetic on every entry of a column!?
- With `SELECT length / 60.0 AS duration`
To add "new" attributes, you specify a constant value `'hours'`. All tuples will have that const value

Selection is done with WHERE
in SQL, `'` single quotes are for strings
- Two `''` single quotes escapes the string meaning. `'Wayne''s world'`
SQL is case insensitive
- So you can do `SELECT`, `select`, whatever you want
