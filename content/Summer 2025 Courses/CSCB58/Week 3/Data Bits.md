The "width" of a wire / the amount of data it can pass.

>- Think of it as lanes on a highway. If an input has $n$ data bits, then it has $n$ "lanes" all of which are $0$'s and $1$'s

Wires with, lets say 4 data bits, can pass values like `1010` or `0011` or `0000` . You get the idea.
You can use something like a splitter to separate the values into individual, 1 data bit wires like we're used to.
