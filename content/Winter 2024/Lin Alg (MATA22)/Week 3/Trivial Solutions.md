>[!thm] The Trivial Solution
>A homogeneous system of $k$ # of variables always has the trivial solution $\vec 0 = (\hat 0, \dots, \hat 0) \in \mathbb F^k$
>>[!explanation] 
>>If we set every coefficient to 0, then we get the constants of 0 for each equation. That is why this property holds.
>
>>[!proof]-
>>In any field we have $\hat 0 + \hat 0 = \hat 0$ and a_{ig}\hat 0 = \hat 0.
>>So for any linear system where 
>>$$
>>\begin{cases}
> a_{11}x_1 + a_{12}x_2 + \dots + a_{1n}x_n &=&& \hat 0 \\
> a_{21}x_1 + a_{22}x_2 + \dots + a_{2n}x_n &=&&\hat 0 \\
> &\vdotswithin{\. } \notag \\
> a_{k1}x_1 + a_{k2}x_2 + \dots + a_{kn}x_n &= &&\hat 0 \\
\end{cases}
>>$$
>>then we get $a_{r1}0 + a_{r2}0 + \dots + a_{rn}0 = 0$ for each row. Therefore $(x_1, x_2 \dots x_n) = (0, \dots, 0)$ is a solution of the system.
>>
